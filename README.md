# ClaudeUI

Десктопная оболочка для [Claude Code](https://docs.anthropic.com/en/docs/claude-code):
сессии во вкладках со встроенным терминалом, нативный редактор `/config`,
лимиты и расход — в одном окне.

*A desktop front-end for Claude Code on Linux: session tabs with an embedded
terminal, a native `/config` editor, usage limits and spend. UI is in Russian.*

> Неофициальный проект, не связан с Anthropic. ClaudeUI запускает установленный
> у вас `claude` и читает его локальные файлы — ни ключей, ни токенов он не трогает.

## Что умеет

- **Сессии.** Список всех сессий из `~/.claude/projects`, сгруппированный по
  папкам, с поиском. Продолжить (`--resume`), начать новую, переименовать,
  удалить. Видно, какие сессии сейчас запущены в других терминалах.
- **Терминал во вкладке.** Свой VT-эмулятор, полноэкранный интерфейс Claude Code
  работает как в обычном терминале. Статус сессии (работает / ждёт ввода /
  ждёт разрешения) — прямо на вкладке.
- **Штатное закрытие.** Вкладка закрывается через `/exit`, чтобы Claude Code
  сохранил сессию; при выходе из приложения — то же для всех вкладок сразу.
- **Настройки `/config`.** Те же параметры, что в `/config`, обычными
  переключателями и списками. Пишет в те же файлы, что и Claude Code
  (`~/.claude/settings.json`, `~/.claude.json` — с той же блокировкой файла).
  Выбор модели — из списка, который знает установленная версия `claude`.
- **Лимиты и расход.** Пятичасовой и недельный лимиты, время сброса, траты по
  открытым сессиям. Данные берутся из кэша Claude Code и обновляются локальной
  командой `claude -p /usage` — токены на это не тратятся.
- **Проверка VPN.** Если трафик идёт через VPN или прокси, перед запуском
  проверяется страна выхода; при выходе через РФ запуск блокируется, а для уже
  запущенной сессии показывается предупреждение.

## Сборка

Нужны Linux, свежий GCC или Clang с поддержкой C++23, CMake 3.21+ и:

| Зависимость     | Arch Linux                         | Debian / Ubuntu                          |
|-----------------|------------------------------------|------------------------------------------|
| GLFW 3          | `glfw`                             | `libglfw3-dev`                           |
| Vulkan          | `vulkan-icd-loader vulkan-headers` | `libvulkan-dev`                          |
| nlohmann/json   | `nlohmann-json`                    | `nlohmann-json3-dev`                     |
| libcurl         | `curl`                             | `libcurl4-openssl-dev`                   |

Dear ImGui (ветка docking) CMake скачает сам.

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/claudeui
```

Для работы нужен установленный и залогиненный `claude`.

### Шрифты

Интерфейс использует системные шрифты:

- `noto-fonts` — текст интерфейса и кириллица;
- `ttf-jetbrains-mono-nerd` — терминал и иконки.

Если у вас есть шрифты Anthropic, их можно положить в `assets/fonts/` — в
репозитории их нет, потому что распространять их нельзя. Подробнее —
[`assets/fonts/README.md`](assets/fonts/README.md).

## Запуск

```
claudeui [--new DIR]... [--resume SESSION_ID]... [--settings]
  --new DIR        открыть новую сессию Claude Code в папке DIR
  --resume ID      продолжить сессию по id
  --settings       открыть сразу вкладку настроек
```

Горячие клавиши: `Ctrl+Shift+T` — новая сессия, `Ctrl+Shift+W` — закрыть вкладку
через `/exit`, `Ctrl+Shift+C` — скопировать выделение в терминале.

Собственные настройки ClaudeUI (шрифт терминала, раскладка панелей) хранятся в
`$XDG_CONFIG_HOME/claudeui/settings.json` — файлы Claude Code для этого не
используются.
